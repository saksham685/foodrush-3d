# 🍔 FoodRush 3D — Premium Food Ordering Experience

A modern, commercial-grade 3D Food Ordering Web Application built with React.js, Vite, CSS 3D Transforms, and Glassmorphism.

![FoodRush 3D](https://images.unsplash.com/photo-1568901346375-23c9450c58cd?w=1200&q=80)

---

## 🌟 Key Features

- **🍔 Interactive 3D Hero Experience:** Real-time mouse-tracking tilt effects, orbital rings, and floating ingredients (tomatoes, lettuce, onions, garlic).
- **📍 Dynamic Location Selector:** Set delivery location anywhere across India (custom text address, popular city pills, and live GPS geolocation).
- **🔍 Universal Food & Restaurant Search:** Instant search by dish names (Biryani, Pizza, Burger, Momos, Pasta, Shawarma, etc.), categories, or restaurants.
- **✨ 3D Category & Restaurant Cards:** 3D perspective tilts, hover scaling, depth shadows, rating chips, and interactive favorites heart toggle.
- **🛒 Dynamic 3D Cart Panel:** Slide-out shopping cart with instant quantity adjustment (`+` / `−`), live subtotal, GST, discounts, and free delivery thresholds.
- **🎉 Interactive Coupon System:** One-click copy coupon cards with animated status badges (`WELCOME50`, `FOOD20`, `FREEDEL`, `RUSH100`).
- **💳 Multi-step Checkout:** Address management, mobile confirmation, UPI / Card / COD payment options.
- **🛵 Live Animated 3D Order Tracking:** Interactive delivery path with moving scooter animation, real-time stage progression, and driver contact.
- **👤 User Profile & Order History:** Saved addresses, gold member badge, and previous orders.
- **📱 Fully Responsive:** Optimized layout across mobile, tablet, laptop, and ultra-wide screens.

## 🚀 Quick Start (Local Run)

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/foodrush-3d.git

# Enter project directory
cd foodrush-3d

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit: `http://localhost:5173`

---

## 🌐 Deploy to Vercel / Netlify in 1 Click

1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Click **"Add New Project"** and select your `foodrush-3d` repository.
4. Framework Preset: **Vite**
5. Click **"Deploy"** — your live website link will be generated in under 1 minute!

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, JavaScript (ES Modules)
- **Styling:** Vanilla CSS3, 3D Transforms (`perspective`, `rotateX`, `rotateY`), Glassmorphism, CSS Variables
- **Icons & Notifications:** Lucide React, React Hot Toast
- **Typography:** Space Grotesk & Playfair Display
